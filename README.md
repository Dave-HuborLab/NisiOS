# NisiOS

**Sistema Operativo interattivo** che illustra il curriculum di **Davide Nisi**.

Un desktop simulato (stile OS moderno) con finestre trascinabili, taskbar, menu Start e un **terminal** funzionale. Tutto statico, pronto per GitHub Pages.

## Contenuto

- **About** — profilo, formazione, referenze
- **Experience** — Caracol AM + background IT
- **Certifications** — Apple (ACMT, ACIT…), Android Enterprise, SCCM, Claude 101
- **Projects** — Emmelibri PDL Rollout e altri
- **Skills** — barre di competenza + stack
- **Terminal** — comandi `whoami`, `certs`, `neofetch`, `help`, ecc.
- **Contact** — link LinkedIn

I dati sono basati sulle informazioni **pubbliche** del profilo LinkedIn:  
[linkedin.com/in/davide-nisi-8a7324137](https://it.linkedin.com/in/davide-nisi-8a7324137)

## Come pubblicare su GitHub Pages

1. Vai su **Settings → Pages**.
2. Source: **Deploy from a branch** → branch `main` → cartella `/ (root)`.
3. Salva. Dopo 1-2 minuti il sito sarà live su:
   `https://Dave-HuborLab.github.io/NisiOS/`

## Personalizzazione

- Modifica i dati in `app.js` (oggetto `PROFILE`, `CERTS`, `PROJECTS`, `SKILLS`).
- Cambia colori e stile in `styles.css` (variabili CSS in `:root`).
